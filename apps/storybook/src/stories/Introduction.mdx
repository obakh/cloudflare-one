# @repo/ui Component Library

Welcome to the UI component library for this monorepo template. This Storybook documents all available components from the `@repo/ui` package.

## Getting Started

Install the package in your app:

```bash
pnpm add @repo/ui
```

Import components:

```tsx
import { Button } from "@repo/ui/button";
import { Card, CardHeader, CardTitle, CardContent } from "@repo/ui/card";
import { Input } from "@repo/ui/input";
```

## Available Components

- **Button** - Primary action buttons with multiple variants
- **Card** - Container component for grouping content
- **Input** - Text input fields
- **Badge** - Status indicators and labels
- **Checkbox** - Boolean selection control
- **Switch** - Toggle control
- **Label** - Form field labels
- **Select** - Dropdown selection
- **Dialog** - Modal dialogs
- **Dropdown Menu** - Context menus
- **Tabs** - Tabbed navigation
- **Tooltip** - Hover information
- **Avatar** - User profile images
- **Skeleton** - Loading placeholders
- **Spinner** - Loading indicators
- **Separator** - Visual dividers
- **Textarea** - Multi-line text input

## Theming

Components support light and dark themes via CSS variables. Use the theme toggle in the toolbar above to preview both modes.

## Built With

- [Radix UI](https://www.radix-ui.com/) - Unstyled, accessible components
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS
- [class-variance-authority](https://cva.style/) - Variant management
