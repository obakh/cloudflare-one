# D1 SQLite Database

Cloudflare D1 is a serverless SQLite database. The `@repo/db/d1` module provides type-safe helpers, batch operations, and Drizzle ORM integration.

## Setup

Add D1 binding to your `wrangler.toml`:

```toml
[[d1_databases]]
binding = "DB"
database_name = "my-database"
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

Create a database:

```bash
npx wrangler d1 create my-database
```

## Basic Queries

```ts
import { query, queryOne, execute } from "@repo/db/d1";

// Select multiple rows
const users = await query<User>(env.DB, "SELECT * FROM users WHERE active = ?", [1]);

// Select single row
const user = await queryOne<User>(env.DB, "SELECT * FROM users WHERE id = ?", [userId]);

// Insert/Update/Delete
const { changes, lastRowId } = await execute(
  env.DB,
  "INSERT INTO users (name, email) VALUES (?, ?)",
  ["John", "john@example.com"]
);
```

## Batch Operations

Execute multiple statements in a single round-trip (implicit transaction):

```ts
import { batch, batchInsert } from "@repo/db/d1";

// Multiple queries
const [users, posts] = await batch(env.DB, [
  { sql: "SELECT * FROM users", params: [] },
  { sql: "SELECT * FROM posts WHERE published = ?", params: [1] },
]);

// Bulk insert
await batchInsert(env.DB, "users", [
  { name: "Alice", email: "alice@example.com" },
  { name: "Bob", email: "bob@example.com" },
  { name: "Charlie", email: "charlie@example.com" },
]);
```

## Transactions

```ts
import { transaction } from "@repo/db/d1";

await transaction(env.DB, async (tx) => {
  tx.execute("INSERT INTO users (name) VALUES (?)", ["John"]);
  tx.execute("INSERT INTO profiles (user_id, bio) VALUES (last_insert_rowid(), ?)", ["Hello!"]);
});
```

## Drizzle ORM

```ts
import { createDrizzleD1 } from "@repo/db/d1";
import { sqliteTable, text, integer } from "drizzle-orm/sqlite-core";

// Define schema
export const users = sqliteTable("users", {
  id: integer("id").primaryKey({ autoIncrement: true }),
  name: text("name").notNull(),
  email: text("email").notNull().unique(),
  createdAt: integer("created_at", { mode: "timestamp" }).default(sql`(unixepoch())`),
});

// Create Drizzle instance
const db = createDrizzleD1(env.DB, { schema: { users } });

// Query with Drizzle
const allUsers = await db.select().from(users);
const user = await db.select().from(users).where(eq(users.id, 1));

// Insert
await db.insert(users).values({ name: "John", email: "john@example.com" });

// Update
await db.update(users).set({ name: "Jane" }).where(eq(users.id, 1));

// Delete
await db.delete(users).where(eq(users.id, 1));
```

## Utility Functions

```ts
import { tableExists, getTableInfo, count, paginate } from "@repo/db/d1";

// Check if table exists
if (await tableExists(env.DB, "users")) {
  // ...
}

// Get table schema
const columns = await getTableInfo(env.DB, "users");
// [{ cid: 0, name: "id", type: "INTEGER", notnull: 0, pk: 1 }, ...]

// Count rows
const total = await count(env.DB, "users");
const activeCount = await count(env.DB, "users", "active = ?", [1]);

// Pagination
const { data, page, perPage, hasMore } = await paginate<User>(
  env.DB,
  "SELECT * FROM users ORDER BY created_at DESC",
  [],
  { page: 1, perPage: 20 }
);
```

## Raw SQL / DDL

```ts
import { raw } from "@repo/db/d1";

// Create tables
await raw(env.DB, `
  CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    created_at INTEGER DEFAULT (unixepoch())
  )
`);
```

## Migrations

Use Wrangler for migrations:

```bash
# Create migration
npx wrangler d1 migrations create my-database create_users_table

# Apply migrations (local)
npx wrangler d1 migrations apply my-database --local

# Apply migrations (remote)
npx wrangler d1 migrations apply my-database --remote
```

Migration file (`migrations/0001_create_users_table.sql`):

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  email TEXT UNIQUE NOT NULL,
  created_at INTEGER DEFAULT (unixepoch())
);

CREATE INDEX idx_users_email ON users(email);
```

## Time Travel (Backups)

D1 automatically maintains point-in-time recovery for the last 30 days:

```bash
# List available bookmarks
npx wrangler d1 time-travel info my-database

# Restore to a specific point
npx wrangler d1 time-travel restore my-database --timestamp "2024-01-15T10:30:00Z"
```

## D1 vs Hyperdrive/PostgreSQL

| Feature | D1 (SQLite) | Hyperdrive (PostgreSQL) |
|---------|-------------|------------------------|
| Use case | Per-user/tenant DBs, edge data | Central database, complex queries |
| Size limit | 10 GB per database | Unlimited |
| Scaling | Horizontal (many small DBs) | Vertical |
| SQL dialect | SQLite | PostgreSQL |
| Import | `@repo/db/d1` | `@repo/db/client` |

## Best Practices

1. **Use batch operations** - Reduces round-trips, runs in implicit transaction
2. **Index frequently queried columns** - SQLite benefits greatly from indexes
3. **Keep databases small** - D1 is optimized for many 10GB databases, not one huge one
4. **Use Time Travel** - Don't manually backup, rely on built-in point-in-time recovery
5. **Prefer Drizzle for complex queries** - Type safety and query building
